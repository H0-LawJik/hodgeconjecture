## Findings

1. **Signs first (attack 6).** Nothing is off. Independent computation: on ℂ/Λ with Λ = ℤω₁ + ℤω₂ and coordinates z = sω₁ + tω₂, multiplication by i sends z to s(iω₁) + t(iω₂). For (ω₁, ω₂) = (c, ic) this is −tω₁ + sω₂, so (s, t) ↦ (−t, s), which is `rot x = ![-x 1, x 0]`. For (ω₁, ω₂) = (c, −ic) it is tω₁ − sω₂, so (s, t) ↦ (t, −s), which is rot⁻¹ x = `![x 1, -x 0]`. The pullbacks: `coordChar 0 ∘ rot = exp(2πi(−x₁)) = (coordChar 1)⁻¹` and `coordChar 1 ∘ rot = coordChar 0`, so rot^* a₀ = −a₁, rot^* a₁ = a₀; for rot⁻¹, a₀ ↦ a₁ and a₁ ↦ −a₀. Probe P2 checks both in Lean, proves `rot ≫ rotInv = 𝟙`, and proves `cohomologyMap ℚ 1 rot ≠ cohomologyMap ℚ 1 rotInv`, so the candidate's `rot_pullback_coordWinding_zero_ne` (rot^* a₀ ≠ a₁) is a test that rot⁻¹ fails. The relations are homogeneous linear in the aᵢ, so they do not depend on the winding normalization ±1/2πi (row "Winding number"); they depend only on the coordinate action of rot. (rot^*)² = −1 and rot^* (a₀ ⌣ a₁) = a₀ ⌣ a₁ hold for rot⁻¹ as well (determinant +1 for both); the H² computation (−a₁) ⌣ a₀ = −(a₁ ⌣ a₀) = a₀ ⌣ a₁ uses `cupSing_gradedComm` at p = q = 1 and is right.
