## General lemmas kept local

Decision 0011: these stay in this repository. A pin bump checks each row for a name clash or a new equivalent in Mathlib or upstream. Rows are grouped by the Mathlib or upstream area they shadow; each category names the directories a bump diffs. Layer is the module's longest import path above Mathlib and upstream, as `python3 tools/pinwalk.py` prints it on 2026-11-27 (one entry per module, `-` for a row with no module yet); the script is the current value, the column a snapshot. Categories run in walk order, lowest layer first, and rows within a category by layer.

**Pin walk.** On a bump, walk the categories in the order below and, inside each, the rows in layer order: diff the named directories between the old and new pin, run `python3 tools/pinwalk.py --clash <new Mathlib or upstream source dir>` for name and phrase candidates, and settle each row (keep, rename, or replace by the new declaration). Then rebuild `HodgeLadder/CycleClass/Pins.lean` (its `rfl` pins break on upstream drift) and re-run the drift list in `docs/conventions.md`. The full procedure is `docs/pin-walk.md`.
